- [x] Land in `src/anytimeacquisition/models/baselines/` — `gp_acquisition.py`:
  `fit_gp` (one independent `SingleTaskGP` per batch instance, fit on
  `-y` since this project minimizes but BoTorch's acquisition functions maximize — the sign flip never leaks past
  `fit_gp`/`gp_acquisition_policy`'s own boundary), `gp_acquisition_policy` (EI/PI/ES, matches

  `LogExpectedImprovement` (BoTorch's own recommended numerics fix over plain `ExpectedImprovement`); ES uses
  `qMaxValueEntropy`
  (the standard, stable entropy-search acquisition in the installed BoTorch version) over a uniform-random discretized
  candidate set. **UCB not built** — also in M6's original scope, trivial to add alongside the other three the same way,
  just not asked for yet.
